# React Basics 🚀

A beginner-friendly React.js project created to learn and practice the fundamental concepts of React, including components, props, state, event handling, hooks, and component re-rendering.

## 📌 About the Project

This repository contains practical examples and exercises developed while learning React.js.

The project focuses on understanding how React applications are structured and how different React features work together to build interactive user interfaces.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Nidhi0318/React-basics.git
```

### 2. Navigate to the project folder

```bash
cd React-basics
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Vite will provide a local development URL in the terminal, usually:

```text
http://localhost:5173/
```

Open this URL in your browser.
